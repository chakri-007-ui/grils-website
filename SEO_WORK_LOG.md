## Measured limits

Google's public PageSpeed API returned HTTP 429 during this audit, so no Lighthouse score is claimed. Local sample encoding at an 828px width reduced the invisible grill hero from 214,879 bytes to 55,532 bytes and the cloth hanger hero from 129,554 bytes to 29,788 bytes. Actual optimized response sizes depend on the browser's requested width and format.
